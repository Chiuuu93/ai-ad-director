① 生成模式
左栏「生成模式」面板
文生首尾帧 — 每镜生成 Start + End 两张 Prompt，描述镜头从开始到结束的视觉变化。适合完整分镜。
文生首帧 — 只生成一张静态图 Prompt。适合单帧出图。
文生视频 — 为 Seedance 2.0 生成运镜描述（Z-axis push-in, Pan, Dolly zoom 等摄影术语）。
为什么要选？因为不同模式 LLM 输出的字段不同：首尾帧输出 start/end 双帧，视频模式强制输出 seedance_motion。
② 平台合规 AD
Topbar 按钮 GG / TT / FB
GG (Google Ads) — 最严格。禁止性暗示、皮肤裸露、约会暗示。负向词追加 cleavage + suggestive pose。
TT (TikTok) — 严格。禁止成人内容暗示，角色必须着装完整。
FB (Meta) — 较宽松。允许展示身材曲线，只禁止露骨内容。
为什么要选？不同平台的 AI 审核模型尺度不同，同一个素材可能 GG 被拒但 FB 能过。切换平台会自动注入对应的负向词和风格约束。
③ 图像模型
Topbar 下拉菜单 🎯
不同模型 prompt 结构不同，选错模型 prompt 效果打折扣：

SD / SDXL / SD3 — CLIP 编码器，token 位置越靠前权重越高。prompt 用 (jet black hair:1.3) 加权语法。身份描述必须放最前面。预算 600-1100 字符。
FLUX.1 — T5 编码器，双向注意力不分位置先后。不用加权语法，用自然逗号分隔。FLUX 对"先描述场景再放人物"的 prompt 响应更好。预算 1400 字符。
GPT Image — 自然语言句号分隔，像写句子一样描述。预算 2000 字符。
Midjourney — 短 prompt（500字符），主体+风格在前，自动追加 --ar 16:9 --style raw 参数。
Seedance 2.0 — 视频模型，场景+运动在前，人物身份在后。预算 1500 字符。
选 Auto 会根据 LLM 模型自动推断。例如选了 GPT Image 相关的 LLM → 自动切 GPT Image prompt 格式。
④ 角色 Anchor（JSON角色锁）
左栏「Role Anchor 2.0」面板 → 编辑 JSON → 点🔒锁定
face_lock / hair_lock / eyes_lock / skin_lock — 刚性锁：LLM 逐字复制到每镜 prompt，不准改动。保证跨镜头脸型/发色/瞳色一致。
outfit_lock / vibe_lock — 边界锁：保持服装类型和色调，LLM 可以加褶皱/面料细节。
composition_constants / style_filter — 构图和风格偏好，注入每镜。
为什么用 JSON 而不是纯文本？JSON 分字段锁定，Coherence Engine 可以逐个维度校验。纯文本一段话没法知道哪部分是脸、哪部分是头发。
⑤ 剧本输入
左栏「剧本输入」面板
写一段故事描述。LLM 会自动拆成你设定的分镜数量。可以用中文写，LLM 输出时 visual 字段自动转英文。也可以「手动编辑分镜表」逐镜细调场景/动作/POV/词典。
⑥ 生成分镜 + Coherence 校验
点击 ⚡ 生成一致性分镜 → Smart Router 自动选最优 LLM → 返回分镜 JSON → Coherence Engine 自动校验每镜发色/瞳色是否与 Anchor 一致 → 通过 ✅ / 漂移 ⚠️ / 冲突 🔴 三种徽章标在每张卡片上。
⑦ 复制 Prompt → 生图
每张分镜卡有 Start Frame 和 End Frame 两个 Prompt 框。点击「复制 Start+Neg」把正向 + 负向 Prompt 一起复制，粘贴到 SD/FLUX/MJ 等生图工具即可。卡片下方有 Seedance 运镜建议和本地化文案。
